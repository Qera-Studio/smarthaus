# Accepted risks

The accepted-risk record `qera-system/gates/launch-gate.md` requires, in its format. A row here is a floor item knowingly shipped unfixed. Resolve-by points are milestones, not calendar dates: the project has no fixed launch date (decided 2026-09-26). Anything past its resolve-by point is no longer an accepted risk: it is an unfixed defect with paperwork, and the next gate run treats it as a NO-GO.
